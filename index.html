👋 What is HV?

HV is a free, open-source desktop application for Windows that completely transforms how you use Hyper-V, the built-in virtualization software from Microsoft. Instead of opening a plain command-line window and typing complicated commands, HV gives you a clean, modern, visual interface. You get access to deep, advanced settings that were previously hidden, all presented in a way that is easy to understand and use.

Whether you are a system administrator, a developer, or an IT enthusiast, HV saves you hours of time. It turns complex PowerShell scripting into simple clicks, toggles, and sliders. No programming skills are required—if you can use a standard Windows program, you can use HV.

✨ What Can You Do with HV?

HV puts a complete toolkit at your fingertips. Here’s a look at what you can control, broken down into simple categories:

🧠 CPU Settings (vCPU)

Fine-tune the virtual processor of your virtual machines. You can adjust the number of cores, reserve power, set performance limits, manage priorities, and even enable advanced compatibility features for older systems. For performance enthusiasts, there are options for CPU pinning, memory caching details, and even confidential computing modes like Intel TDX and AMD SEV-SNP.

💾 Memory Management

Control exactly how your virtual machines use memory. Set startup memory, dynamic memory ranges, and memory weights. Choose the memory page size for optimal performance (4K, 2M, or 1G). You can also enable memory encryption, adjust NUMA settings, and configure special Intel SGX enclaves for security-sensitive tasks.

💽 Storage & Drives

Effortlessly connect virtual hard drives (VHD or VHDX), ISO images, and even physical disks. HV makes storage configuration straightforward, so you can quickly add or remove drives without touching a single command.

🛠️ And Much More: HV covers every major aspect of Hyper-V, including network settings, security features, and system-wide resource protections. It’s your all-in-one command center.

🖥️ System Compatibility

HV is designed to work seamlessly on modern Windows systems. It is built specifically for Windows and supports both standard and newer processor architectures. You can run it on most Windows 10 or Windows 11 computers.

  • Operating System: Windows 10 or Windows 11 (64-bit)
  • Processor Architecture: Works on both standard Intel/AMD (x64) and newer ARM-based (arm64) Windows devices.
  • Requirement: You must have the Hyper-V feature enabled in Windows. This is a standard Windows feature, not something HV needs to install.

If you're not sure if your PC supports it, simply try running HV. It will be clear if it's not compatible, but for almost all modern PCs, it will work perfectly out of the box.
